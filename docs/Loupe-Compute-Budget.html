Loupe · Funding request · Phase R experiments

Language-model API budget for the Loupe replication study

Loupe's first phase rebuilds a published multi-agent system (FARE, IEEE Access 2026) and tests its claims on SEC filings for 19 companies. The experiments call hosted language models a few hundred thousand times. This page states what we need, why, what it costs at today's published prices, and how we will keep spending under control.

2 · Why paid access

Free tiers cannot run a controlled experiment

VOLUME

The core design runs about 1,700 queries per model across four models and four baselines, and every answer is scored by a judge model. That is several thousand calls a day during runs. Free-tier daily request limits are set per project and change without notice.

SAME MODELS AS THE PAPER

To test FARE's claims we must use FARE's four models. Two are Google models; the other two are open models that are only practical through a paid host unless we run them on a free Colab GPU, which is slow and gets interrupted.

DATA TERMS

Google's pricing page states that free-tier prompts are used to improve its products, and paid-tier prompts are not. Our data is public filings, so this is not a privacy problem, but a paid tier gives a cleaner research record.

JUDGE NEEDS SEARCH

FARE's judges check answers against Google Search results. On the paid tier, 1,500 grounded requests a day are free; the free tier allows 500. That alone decides how many days judging takes.

No hardware is requested. Embeddings (all-MiniLM-L6-v2), the vector index (FAISS) and the results store (DuckDB) run on our own laptops.

5 · Spend controls

How the money is protected

1

Prepaid credit and hard caps

OpenRouter is prepaid, so it cannot overspend. The Google account gets a monthly spending cap equal to the released amount.

2

Nothing is paid for twice

Every model call goes through one gateway that caches responses by model, prompt and settings. Re-running an analysis reads from the cache.

3

Every call is logged with its cost

The gateway writes tokens, latency and cost for each call. The guide receives a one-page spend report at the end of each month and before the second release.

4

Keys stay private

API keys live in a local .env file that git ignores. One key per provider, rotated if anyone leaves the project.

6 · Without funding

What we can still do for ₹0, and what is lost

STILL POSSIBLE
  • Gemini 2.5 Flash-Lite on the free tier, dev companies first
  • Qwen2.5-7B and Llama-3.2-3B on a free Colab T4 GPU, as FARE did
  • Q-XBRL and routing results, which need no judge
  • Human grading of H-120
LOST OR WEAKENED
  • Gemini 2.5 Flash at full scale, so claims C1 to C4 are only partly testable
  • The stage-by-stage study (RQ4) shrinks to two or three variants
  • Judging limited to 500 grounded requests a day, so runs take weeks
  • No insurance against the Gemini 2.5 retirement
